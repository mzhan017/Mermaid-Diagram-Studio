# Mermaid 画图工具（Windows）

这是一个免安装的小工具，适用于 Windows 10/11。无需安装 Node.js 或 Python。

## 使用方法

1. 双击 `启动Mermaid画图工具.bat`，或直接用 Edge/Chrome 打开 `Mermaid-Diagram-Studio.html`。
2. 在左侧编辑 Mermaid 代码，点击“生成图表”或按 `Ctrl+Enter`。
3. 通过示例菜单插入流程图、时序图、类图、实体关系图、状态图、甘特图和饼图。
4. 点击“导出 SVG”保存矢量图，或点击“导出 JPG”保存白色背景的 JPG 图片；也可以点击“复制代码”复制 Mermaid 源码。

首次打开需要联网加载 Mermaid 渲染库（jsDelivr CDN）。编辑和渲染均在本机浏览器中进行，代码不会上传到本工具的服务器。
